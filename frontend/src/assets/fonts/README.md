# Font Assets

Place the following Space Grotesk woff2 files here (OFL license — free to bundle):

- `SpaceGrotesk-Regular.woff2` (weight 400)
- `SpaceGrotesk-Medium.woff2` (weight 500)
- `SpaceGrotesk-SemiBold.woff2` (weight 600)

Download from: https://github.com/floriankarsten/space-grotesk/tree/master/fonts/webfonts
Or via Google Fonts download: https://fonts.google.com/specimen/Space+Grotesk (Download family → extract woff2 files)
